<channel|>To design this dataclass correctly, it is important to use `field(default_factory=list)` for the `roles` attribute. 

In Python, you should **never** use a mutable default value like `roles: list = []` directly in a class definition, as that list would be shared across all instances of the class. Using `default_factory` ensures that every new `User` object gets its own unique list.

Here is the implementation:

```python
from dataclasses import dataclass, field
from typing import List

@dataclass
class User:
    id: int
    name: str
    email: str
    # We use default_factory to ensure each instance gets a NEW list object
    roles: List[str] = field(default_factory=list)
