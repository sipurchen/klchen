Here are three ways to rewrite this, depending on how you want to handle the error.

### Option 1: The Robust Approach (Recommended)
This version catches specific errors and returns a helpful message or `None`, preventing the entire program from crashing.

```python
def read_file(path):
    try:
        with open(path, 'r', encoding='utf-8') as file:
            return file.read()
    except FileNotFoundError:
        print(f"Error: The file at '{path}' was not found.")
        return None
    except PermissionError:
        print(f"Error: Permission denied when trying to read '{path}'.")<end_of_turn>
