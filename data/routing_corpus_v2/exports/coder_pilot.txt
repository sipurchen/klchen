# Project Spec: Type-Validated CSV-to-JSON Converter

## 1. Project Objective
To create a command-line utility that transforms a CSV file into a structured JSON array, ensuring that every value adheres to a predefined schema (data types). This prevents "dirty data" from entering downstream systems.

## 2. Core Goals
*   **Data Integrity:** Ensure that columns intended to be numbers or booleans are correctly cast and validated.
*   **Error Reporting:** Instead of crashing on a bad row, the tool should log specific errors (e.g., "Row 5, Column 'Age': expected int, got 'abc'") and either skip the row or halt.
*   **Schema-Driven:** The conversion logic should be dictated by a "schema" (a mapping of column names to types) rather than hard-coded logic.

## 3. Input / Output

### Inputs
1.  **Source File (`.csv`):** A standard comma-separated values file.
2.  **Schema Definition:** A dictionary or a separate JSON file defining the expected types for each column.
    *   *Supported Types:* `string`, `int`, `float`, `bool`.

### Outputs
1.  **Target File (`.json`):** A JSON file containing an array of objects, where each object represents a valid CSV row with correctly typed values.
2.  **Error Log (Optional):** A report of any rows that failed validation and why.

## 4. Main Functions (Logic Flow)

### `load_schema(schema_path)`
*   Reads the schema definition file.
*   **Returns:** A dictionary mapping column headers to type identifiers.

### `validate_and_cast(value, target_type)`
*   The "engine" of the project. Takes a raw string from the CSV and attempts to convert it to the `target_type`.
*   **Logic:** 
    *   If `int`: Try `int(value)`.
    *   If `float`: Try `float(value)`.
    *   If `bool`: Check if value is `true`/`false` (case-insensitive).
*   **Returns:** The converted value or raises a `ValueError` if conversion fails.

### `process_csv(csv_path, schema)`
*   The orchestrator.
*   Iterates through the CSV rows using Python’s `csv.DictReader`.
*   For every row:
    1.  Iterate through the columns defined in the schema.
    2.  Call `validate_and_cast` for each column.
    3.  If a value fails, catch the error, log it, and decide whether to skip the row or stop execution.
    4.  If all columns pass, add the cleaned dictionary to a list.
*   **Returns:** A list of validated dictionaries.

### `save_json(data, output_path)`
*   Takes the list of validated dictionaries and writes them to a file using `json.dump()`.

## 5. Error Handling Strategy
*   **Strict Mode (Default):** If a single cell fails validation, the entire process stops and reports the error.
*   **Permissive Mode (Optional):** If a cell fails, the row is skipped, the error is logged to the console, and the process continues to the next row.

Following the specification we laid out, here is the complete implementation. I have structured this as a robust, reusable module with a Command Line Interface (CLI).

```python
import csv
import json
import sys
from typing import Any, Dict, List, Union

class CSVConverterError(Exception):
    """Custom exception for converter-specific errors."""
    pass

class CSVToJSONConverter:
    def __init__(self, schema: Dict[str, str], strict: bool = True):
        """
        Initialize the converter.
        
        :param schema: Dictionary mapping column names to types ('int', 'float', 'string', 'bool')
        :param strict: If True, stops execution on the first validation error. 
                       If False, skips the bad row and continues.
        """
        self.schema = schema
        self.strict = strict
        # Map string type names to actual conversion functions
        self._type_map = {
            'int': int,
            'float': float,
            'string': str,
            'bool': self._str_to_bool
        }

    def _str_to_bool(self, value: str) -> bool:
        """Helper to handle boolean conversion from strings."""
        normalized = value.strip().lower()
        if normalized in ('true', '1', 't', 'yes', 'y'):
            return True
        if normalized in ('false', '0', 'f', 'no', 'n'):
            return False
        raise ValueError(f"Cannot convert '{value}' to boolean")

    def validate_and_cast(self, value: str, target_type: str) -> Any:
        """Attempts to cast a string value to the specified type."""
        if target_type not in self._type_map:
            raise CSVConverterError(f"Unsupported type in schema: {target_type}")
        
        try:
            return self._type_map[target_type](value)
        except ValueError as e:
            raise ValueError(f"Expected {target_type}, got '{value}'") from e

    def process_csv(self, csv_path: str) -> List[Dict[str, Any]]:
        """Reads CSV, validates against schema, and returns a list of dicts."""
        validated_data = []
        
        try:
            with open(csv_path, mode='r', encoding='utf-8') as csvfile:
                reader = csv.DictReader(csvfile)
                
                # Check if all schema columns exist in the CSV header
                if not all(col in reader.fieldnames for col in self.schema):
                    missing = set(self.schema.keys()) - set(reader.fieldnames)
                    raise CSVConverterError(f"CSV is missing required columns: {missing}")

                for row_idx, row in enumerate(reader, start=1):
                    try:
                        new_row = {}
                        # We only process columns defined in our schema
                        for col_name, target_type in self.schema.items():
                            raw_value = row[col_name]
                            new_row[col_name] = self.validate_and_cast(raw_value, target_type)
                        
                        # Add other columns not in schema as strings (optional behavior)
                        for col_name in reader.fieldnames:
                            if col_name not in self.schema:
                                new_row[col_name] = row[col_name]

                        validated_data.append(new_row)

                    except ValueError as e:
                        error_msg = f"Row {row_idx} Validation Error: {e}"
                        if self.strict:
                            raise CSVConverterError(error_msg)
                        else:
                            print(f"Skipping {error_msg}", file=sys.stderr)
                            continue

        except FileNotFoundError:
            raise CSVConverterError(f"File not found: {csv_path}")
        except Exception as e:
            raise CSVConverterError(f"An unexpected error occurred: {e}")

        return validated_data

    def save_json(self, data: List[Dict[str, Any]], output_path: str):
        """Writes the validated data to a JSON file."""
        try:
            with open(output_path, mode='w', encoding='utf-8') as jsonfile:
                json.dump(data, jsonfile, indent=4)
        except Exception as e:
            raise CSVConverterError(f"Failed to save JSON: {e}")


def main():
    """
    Example CLI usage.
    To run: python script.py input.csv output.json
    """
    if len(sys.argv) < 3:
        print("Usage: python script.py <input_csv> <output_json> [--permissive]")
        return

    input_file = sys.argv[1]
    output_file = sys.argv[2]
    
    # Check for permissive flag
    is_permissive = "--permissive" in sys.argv

    # DEFINING THE SCHEMA
    # In a real-world app, this might be loaded from a schema.json file
    schema = {
        "id": "int",
        "name": "string",
        "price": "float",
        "is_available": "bool"
    }

    converter = CSVToJSONConverter(schema, strict=not is_permissive)

    try:
        print(f"Starting conversion: {input_file} -> {output_file}")
        data = converter.process_csv(input_file)
        converter.save_json(data, output_file)
        print(f"Success! Processed {len(data)} rows.")
    except CSVConverterError as e:
        print(f"ERROR: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    main()
```
