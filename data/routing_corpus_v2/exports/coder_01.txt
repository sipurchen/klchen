# Specification: Python Retry-Queue (PRQ)

## 1. Project Goals
*   **Reliability:** Ensure that tasks are not lost due to transient errors (e.g., network timeouts).
*   **Resilience:** Implement an exponential backoff strategy to prevent overwhelming downstream services during failure loops.
*   **Simplicity:** Provide a clean, decorator-based or object-oriented API that is easy to integrate into existing Python scripts.
*   **Decoupling:** Separate the definition of the task (the logic) from the execution logic (the retry/backoff policy).

## 2. Core Components

### A. The `Task` Object
A data container representing a single unit of work.
*   **Attributes:**
    *   `func`: The callable to be executed.
    *   `args`: Positional arguments for the function.
    *   `kwargs`: Keyword arguments for the function.
    *   `retries_remaining`: Integer tracking how many attempts are left.
    *   `next_run_time`: A timestamp indicating when the task is eligible to run again.
    *   `delay_multiplier`: The base factor used for exponential backoff.

### B. The `TaskQueue` Manager
The orchestrator that manages the lifecycle of tasks.
*   **Responsibilities:**
    *   Holding the queue of pending tasks.
    *   Scheduling tasks for future execution based on backoff timers.
    *   Providing an interface to add new tasks.

### C. The `Worker`
The execution engine that pulls tasks from the queue.
*   **Responsibilities:**
    *   Monitoring the queue for "ready" tasks.
    *   Executing the task and catching exceptions.
    *   Calculating backoff intervals upon failure.
    *   Re-enqueuing tasks if retries are available.

## 3. Main Functions

| Function | Input | Output | Description |
| :--- | :--- | :--- | :--- |
| `enqueue(func, args, kwargs, max_retries, base_delay)` | A callable and configuration parameters. | `Task` object added to queue. | Creates a new `Task` and places it in the immediate execution queue. |
| `process_next()` | None | `None` | Pulls the next available task from the queue and attempts execution. |
| `calculate_backoff(retry_count, base_delay)` | `retry_count` (int), `base_delay` (float) | `float` (seconds) | Computes $base\_delay \times 2^{retry\_count}$ to determine wait time. |
| `handle_failure(task, exception)` | `Task` object, `Exception` | `None` | Decrements retry count; if $>0$, calculates new `next_run_time` and re-enqueues. |

## 4. Data Flow (The Retry Loop)

1.  **Submission:** User calls `enqueue()`. A `Task` is created and placed in a `PriorityQueue` (sorted by `next_run_time`).
2.  **Execution:** The `Worker` checks the head of the queue. If `now() >= task.next_run_time`, it executes `task.func`.
3.  **Success Path:** If `task.func` returns successfully, the task is marked complete and removed.
4.  **Failure Path:**
    *   If an exception is raised, `handle_failure()` is called.
    *   If `retries_remaining > 0`:
        *   Calculate new delay: $delay = base\_delay \times 2^{attempts\_made}$.
        *   Update `task.next_run_time = now() + delay`.
        *   Update `task.retries_remaining -= 1`.
        *   Re-insert the task into the queue.
    *   If `retries_remaining == 0`:
        *   Log a permanent failure and discard the task.<turn|>

Here is the implementation of the **Python Retry-Queue (PRQ)** based on the specification provided.

I have used `dataclasses` for the `Task` structure and `threading` to allow the `Worker` to run in the background, simulating a real-world asynchronous environment.

```python
import time
import logging
import threading
import queue
from dataclasses import dataclass, field
from typing import Callable, Any, Tuple, Dict

# Configure logging to track task progress and retries
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)
logger = logging.getLogger("PRQ")

@dataclass(order=True)
class Task:
    """
    Represents a unit of work. 
    The 'order=True' and placing 'next_run_time' first allows the 
    PriorityQueue to sort tasks by their scheduled execution time.
    """
    next_run_time: float
    func: Callable = field(compare=False)
    args: Tuple = field(default_factory=tuple, compare=False)
    kwargs: Dict = field(default_factory=dict, compare=False)
    retries_remaining: int = field(default=0, compare=False)
    base_delay: float = field(default=1.0, compare=False)
    attempts_made: int = field(default=0, compare=False)

class TaskQueue:
    """Man:ages the storage and retrieval of tasks."""
    def __init__(self):
        self._queue = queue.PriorityQueue()

    def enqueue(self, func: Callable, args: Tuple = (), kwargs: Dict = None, 
                max_retries: int = 3, base_delay: float = 1.0):
        """Creates a new Task and adds it to the queue."""
        kwargs = kwargs or {}
        new_task = Task(
            next_run_time=time.time(),
            func=func,
            args=args,
            kwargs=kwargs,
            retries_remaining=max_retries,
            base_delay=base_delay,
            attempts_made=0
        )
        self._queue.put(new_task)
        logger.info(f"Enqueued task: {func.__name__} (Retries left: {max_retries})")

    def get_next_task(self, timeout: float = 1.0) -> Task:
        """Retrieves the next task from the queue."""
        try:
            return self._queue.get(timeout=timeout)
        except queue.Empty:
            return None

    def re_enqueue(self, task: Task):
        """Puts a task back into the queue (used for retries)."""
        self._queue.put(task)

class Worker(threading.Thread):
    """The execution engine that processes tasks from the TaskQueue."""
    def __int__(self):
        super().__init__()
        self.running = True

    def __init__(self, task_queue: TaskQueue):
        super().__init__()
        self.task_queue = task_queue
        self.running = True
        self.daemon = True  # Thread dies when main program exits

    def calculate_backoff(self, attempts_made: int, base_delay: float) -> float:
        """Implementation of exponential backoff: base * 2^attempts."""
        return base_delay * (2 ** attempts_made)

    def run(self):
        logger.info("Worker started.")
        while self.running:
            task = self.task_queue.get_next_task(timeout=1.0)
            
            if task is None:
                continue

            # Check if the task is ready to run (handles backoff delay)
            now = time.time()
            if task.next_run_time > now:
                # Not time yet, put it back and wait a bit
                self.task_queue.re_enqueue(task)
                time.sleep(0.1)
                continue

            self._execute_task(task)

    def _execute_task(self, task: Task):
        """Logic for executing a single task and handling the outcome."""
        try:
            logger.info(f"Executing: {task.func.__name__} (Attempt {task.attempts_made + 1})")
            task.func(*task.args, **task.kwargs)
            logger.info(f"Successfully completed: {task.func.__name__}")
        
        except Exception as e:
            logger.error(f"Task failed: {task.func.__name__} | Error: {e}")
            self._handle_failure(task, e)

    def _handle_failure(self, task: Task, error: Exception):
        """Logic for managing retries and exponential backoff."""
        if task.retries_remaining > 0:
            task.retries_remaining -= 1
            task.attempts_made += 1
            
            delay = self.calculate_backoff(task.attempts_made, task.base_delay)
            task.next_run_tme = time.time() + delay
            
            logger.warning(
                f"Retrying {task.func.__name__} in {delay:.2f}s. "
                f"({task.retries_remaining} retries left)"
            )
            # Re-calculate the actual run time
            task.next_run_time = time.time() + delay
            self.task_queue.re_enqueue(task)
        else:
            logger.error(f"Task {task.func.__name__} failed permanently after all retries.")

# --- Demonstration Code ---

def unreliable_task(name: str, fail_until_attempt: int):
    """A dummy task that fails a specific number of times before succeeding."""
    # We use a global/static counter for demo purposes to simulate state
    if not hasattr(unreliable_task, "_counter"):
        unreliable_task._counter = 0
    
    unreliable_task._counter += 1
    
    if unreliable_task._counter <= fail_until_attempt:
        raise ValueError(f"Simulated transient error (Attempt {unlar_task._counter})")
    print(f"--- Task '{name}' actually finished successfully! ---")

def permanent_failure_task():
    """A task that will always fail."""
    raise RuntimeError("This is a fatal error.")

if __name__ == "__main__":
    # 1. Initialize Queue and Worker
    my_queue = TaskQueue()
    worker_thread = Worker(my_queue)
    worker_thread.start()

    # 2. Enqueue a task that will succeed after 2 failures
    # base_delay=1s -> 1st retry at 2s, 2nd retry at 4s...
    my_queue.enqueue(unreliable_task, args=("RecoverableTask", 2), max_retries=3, base_delay=1.0)

    # 3. Enqueue a task that will fail permanently
    my_queue.enqueue(permanent_failure_task, max_retries=2, base_delay=1.0)

    # Keep main thread alive to watch the execution
    try:
        time.sleep(15)
        print("\nDemonstration complete. Shutting down.")
    except KeyboardInterrupt:
        pass
```

### Key Implementation Details:
1.  **`Task` Sorting:** By using `@dataclass(order=True)` and placing `next_run_time` as the first field, the `PriorityQueue` automatically keeps the task with the *earliest* timestamp at the top.
2.  **The "Wait" Mechanism:** In `Worker.run`, if the worker pulls a task whose `next_run_time` hasn't arrived yet, it puts it back in the queue. This allows the queue to "sleep" until the backoff period expires.
3.  **Thread Safety:** I used `queue.PriorityQueue`, which is inherently thread-safe, meaning the `Worker` thread and the `Main` thread can interact with the queue without race conditions.
4.  **Exponential Backoff:** The formula `base_delay * (2 ** attempts_made)` ensures that the delay grows exponentially (1s, 2s, 4s, 8s...), reducing pressure on the system during outages.<turn|>
