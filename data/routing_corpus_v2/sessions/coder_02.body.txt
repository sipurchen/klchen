# Specification: Simple LRU Cache

## 1. Overview
The goal is to implement a Least Recently Used (LRU) cache. The cache will store a fixed number of items. When the cache reaches its capacity and a new item is added, the item that has not been accessed for the longest period must be evicted to make room.

## 2. Project Goals
*   **Efficiency:** Achieve $O(1)$ average time complexity for both `get` and `put` operations.
*   **Self-Management:** The cache must automatically handle eviction without external logic.
*   **Zero Dependencies:** Implement the underlying logic using only Python primitives (no `collections.OrderedDict` or `functools.lru_cache`).

## 3. Data Structure Strategy
To meet the $O(1)$ goal, the implementation will use:
1.  **A Doubly Linked List:** To maintain the order of usage. 
    *   The "Head" will represent the *Most Recently Used* (MRU) item.
    *   The "Tail" will represent the *Least Recently Used* (LRU) item.
2.  **A Dictionary (Hash Map):** To store keys and map them to their corresponding nodes in the linked list, allowing for instant access to any node.

## 4. API Reference

### `LRUCache(capacity: int)`
*   **Input:** An integer representing the maximum number of items the cache can hold.
*   **Output:** An initialized instance of the cache.
*   **Constraint:** `capacity` must be greater than 0.

### `get(key: Any) -> Any`
*   **Input:** A unique identifier (key).
*   **Logic:** 
    *   If the key exists in the cache, move the corresponding node to the "Head" (marking it as most recent) and return its value.
    *   If the key does not exist, return a sentinel value (e.g., `None`).
*   **Output:** The value associated with the key, or `None`.

### `put(key: Any, value: Any) -> None`
*   **Input:** A unique identifier (key) and the data to store (value).
*   **Logic:**
    *   If the key already exists, update its value and move the node to the "Head".
    *   If the key is new:
        *   Create a new node.
        *   If the cache is at `capacity`, identify the node at the "Tail," remove it from the dictionary, and delete it from the list.
        *   Insert the new node at the "Head".
*   **Output:** None.

## 5. Success Criteria
*   **Correct Eviction:** Adding an item to a full cache removes the correct (oldest) item.
*   **Update Logic:** Updating an existing key correctly moves it to the "most recent" position.
*   **Edge Cases:** The cache handles a capacity of 1 and handles frequent updates to the same key without leaking memory or breaking the list pointers.<turn|>

Using dummy nodes is a best practice that eliminates the need for edge-case checks (like checking if the list is empty) every time you add or remove a node.

```python
class Node:
    """A node in the doubly linked list."""
    def __init__(self, key=None, value=None):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("Capacity must be greater than 0")
            
        self.capacity = capacity
        self.cache = {}  # Maps key -> Node
        
        # Initialize dummy head and tail to simplify insertion/deletion logic
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node: Node):
        """Removes a node from the linked list."""
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node

    def _add_to_head(self, node: Node):
        """Adds a node immediately after the dummy head (Most Recently Used)."""
        node.prev = self.head
        node.next = self.head.next
        
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        """
        Retrieves value by key. 
        Moves the accessed node to the head of the list.
        """
        if key in self.cache:
            node = self.cache[key]
            self._remove(node)
            self._add_to_head(node)
            return node.value
        return None

    def put(self, key, value) -> None:
        """
        Inserts or updates a key-value pair.
        Evicts the least recently used item if capacity is exceeded.
        """
        if key in self.cache:
            # If key exists, remove the old node position first
            self._remove(self.cache[key])
        
        # Create/Update node and move to head
        new_node = Node(key, value)
        self.cache[key] = new_node
        self._add_to_head(new_node)
        
        # Check if we exceeded capacity
        if len(self.cache) > self.capacity:
            # The LRU node is the one right before the dummy tail
            lru_node = self.tail.prev
            self._remove(lru_node)
            del self.cache[lru_node.key]
```

```python
import pytest
from lru_cache import LRUCache

def test_normal_flow():
```
