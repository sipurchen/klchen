# Project Specification: `md2html-lib`

## 1. Project Overview
`md2html-lite` is a lightweight Python command-line interface (CLI) utility designed to convert a specific subset of Markdown syntax into valid, well-formatted HTML. The goal is to create a functional, dependency-free (using only Python Standard Library) converter for basic documentation needs.

## 2. Core Goals
*   **Simplicity:** Focus on a minimal set of Markdown features to ensure high reliability.
*   **Portability:** The tool should run anywhere Python is installed without needing `pip install`.
*   **Clarity:** Produce clean, readable HTML output with a standard boilerplate structure.
*   **CLI Usability:** Provide a simple command-line interface that accepts input files and generates output files.

## 3. Functional Requirements

### 3.1 Supported Syntax (The "Scope")
The converter will recognize and transform the following:
*   **Headings:** ATX-style headings (e.g., `# Heading 1`, `## Heading 2`).
*   **Unordered Lists:** Lines starting with `-` or `*`.
*   **Links:** Inline links in the format `[Link Text](URL)`.
*   **Paragraphs:** Any line of text not identified as a heading or list item should be wrapped in `<p>` tags.

### 3.2 Conversion Logic
*   **Block-level Parsing:** The engine must identify block elements (Headings, Lists, Paragraphs) and manage state (e.g., knowing when to open and close a `<ul>` tag).
*   **Inline Parsing:** The engine must scan within lines to replace Markdown link syntax with `<a>` tags.
*   **HTML Boilerplate:** The output must be wrapped in a standard HTML5 skeleton (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).

### 3.3 Command Line Interface
*   The script must accept a positional argument: `input_file.md`.
*   (Optional) The script should allow an optional argument for an `output_file.html`. If not provided, it should default to `input_file.html`.
*   The script must handle errors gracefully (e.g., "File not found" or "Permission denied").

## 4. Input and Output

### 4.1 Input
*   **Format:** Plain text `.md` files.
*   **Encoding:** UTF-8.

### 4.2 Output
*   **Format:** Valid `.html` files.
*   **Structure Example:**
    ```html
    <!DOCTYPE html>
    <html>
    <head><title>Converted Document</title></head>
    <body>
      <h1>Title</h1>
      <p>This is a <a href="https://google.com">link</a>.</p>
      <ul>
        <li>List item</li>
      </ul>
    </body>
    </html>
    ```

## 5. Technical Constraints
*   **Language:** Python 3.x.
*   **Dependencies:** None (Standard Library only: `sys`, `re`, `argparse`).
*   **Approach:** Regular Expression (Regex) based parsing.

```python
#!/usr/bin/env python3
import re
import argparse
import sys
from pathlib import Path

class MarkdownConverter:
    """
    A parser that converts a subset of Markdown (Headings, Lists, Links) 
    into HTML.
    """

    def __init__(self):
        # Regex Patterns
        self.re_heading = re.compile(r'^(#{1,6})\s+(.*)$')
        self.re_list_item = re.compile(r'^[\*\-]\s+(.*)$')
        self.re_link = re.compile(r'\[(.*?)\]\((.*?)\)')
        
        # State tracking
        self.in_list = False

    def _process_inline(self, text: str) -> str:
        """Handles inline elements like links."""
        # Replace [text](url) with <a href="url">text</a>
        return self.re_link.sub(r'<a href="\2">\1</a>', text)

    def convert_lines(self, lines: list[str]) -> str:
        """
        Iterates through lines of markdown and applies block-level 
        and inline transformations.
        """
        html_output = []
        
        for line in lines:
            stripped = line.strip()
            
            # Skip empty lines
            if not stripped:
                continue

            # 1. Check for Headings
            heading_match = self.re_heading.match(stripped)
            
            # 2. Check for List Items
            list_match = self.re_list_item.match(stripped)

            if heading_match:
                # If we were in a list, close it
                if self.in_list:
                    html_output.append("</ul>")
                    self.in_list = False
                
                level = len(heading_match.group(1))
                content = self._process_inline(heading_match.group(2))
                html_output.append(f"<h{level}>{content}</h{level}>")

            elif list_match:
                # If we are starting a new list, open the tag
                if not self.in_list:
                    html_output.append("<ul>")
                    self.in_list = True
                
                content = self._process_inline(list_match.group(1))
                html_output.append(f"  <li>{content}</li>")

            else:
                # 3. Handle Paragraphs
                # If we were in a list, close it
                if self.in_list:
                    html_output.append("</ul>")
                    self.in_list = False
                
                content = self._process_inline(stripped)
                html_output.append(f"<p>{content}</p>")

        # Final cleanup: if the file ends while a list is still open
        if self.in_list:
            html_output.append("</ul>")

        return "\n".join(html_output)

    def wrap_boilerplate(self, body_content: str) -> str:
        """Wraps the converted body in standard HTML5 boilerplate."""
        return (
            "<!DOCTYPE html>\n"
            "<html>\n"
            "<head>\n"
            "    <meta charset='utf-8'>\n"
            "    <title>Converted Markdown</title>\n"
            "</head>\n"
            "<body>\n"
            f"{body_content}\n"
            "</body>\n"
            "</html>"
        )

def main():
    parser = argparse.ArgumentParser(
        description="Convert a simple Markdown file to HTML."
    )
    parser.add_argument(
        "input", 
        help="Path to the input Markdown (.md) file"
    )
    parser.add_argument(
        "-o", "--output", 
        help="Path to the output HTML file (defaults to input name with .html extension)"
    )

    args = parser.parse_args()
    input_path = Path(args.input)

    # Check if input file exists
    if not input_path.is_file():
        print(f"Error: File '{args.input}' not found.", file=sys.stderr)
        sys.exit(1)

    # Determine output path
    if args.output:
        output_path = Path(args.output)
    else:
        output_path = input_path.with_suffix('.html')

    try:
        # Read input
        with open(input_path, 'r', encoding='utf-8') as f:
            md_lines = f.readlines()

        # Convert
        converter = MarkdownConverter()
        converted_body = converter.convert_lines(md_lines)
        final_html = converter.wrap_boilerplate(converted_body)

        # Write output
        with open(output_path, 's', encoding='utf-8') as f:
            f.write(final_html)
        
        print(f"Successfully converted '{input_path}' to '{output_path}'")

    except Exception as e:
        print(f"An error occurred: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    main()
```

### Analysis of the Failure

The error message tells us exactly what went wrong:
*   **Expected:** A nested structure: `<ul><li>a<ul><li>b</li></ul></li></ul>`
*   **Actual:** A flat structure: `<ul><li>a</li><li>b</li></ul>`

#### Why is this happening?
The failure is happening because the current implementation of `MarkdownConverter` is a **Linear Single-Level Parser**. 

Looking back at the logic in `convert_lines`:
1.  It iterates through lines one by one.
2.  It checks if a line is a heading, a list item, or a paragraph.
3.  It uses a single boolean flag, `self.in_list`, to track if we are currently inside a list.

**The limitation:**
When the parser encounters "Item B" after "Item A", it sees that "Item B" matches the `re_list_item` pattern. Because `self.in_list` is already `True`, it simply treats "Item B" as another `<li>` within the *same* existing `<ul>` block. 

The parser **has no concept of depth or indentation**. To support nested lists, the parser would need to:
1.  Measure the leading indentation (whitespace) of each line.
2.  Maintain a **stack** of list levels rather than a single boolean flag.
3.  Compare the current line's indentation to the previous line's indentation to decide whether to open a new `<ul>` or close the current one.

Currently, the code is "flat"—it treats all lines starting with `-` or `*` as being at the same hierarchical level.

### The Fix

To fix this, we need to move away from a boolean `in_list` and toward an **indented-based stack**. We will track the indentation level of the current list.

Here is the corrected `MarkdownConverter` class:

```python
import re

class MarkdownConverter:
    def __init__(self):
        self.re_heading = re.compile(r'^(#{1,6})\s+(.*)$')
        self.re_list_item = re.compile(r'^([\*\-\s]+)(.*)$') # Capture indentation
        self.re_link = re.compile(r'\[(.*?)\]\((.*?)\)')
        # Track the stack of indentation levels for nested lists
        # Stores tuples of (indent_level, tag_is_open)
        self.list_stack = [] 

    def _process_inline(self, text: str) -> str:
        return self.re_link.sub(r'<a href="\2">\1</a>', text)

    def convert_lines(self, lines: list[str]) -> str:
        html_output = []
        
        for line in lines:
            stripped = line.lstrip()
            if not stripped:
                continue

            heading_match = self.re_heading.match(line.strip())
            list_match = self.re_list_item.match(line)

            # Helper to close all open lists in the stack
            def close_all_lists():
                while self.list_stack:
                    html_output.append("</ul>")
                    self.list_stack.pop()

            if heading_match:
                close_all_lists()
                level = len(heading_match.group(1))
                content = self._process_inline(heading_match.group(2))
                html_output.append(f"<h{level}>{content}</h{level}>")

            elif list_match:
                # Calculate indentation level based on leading whitespace/chars
                prefix = list_match.group(1)
                indent_level = len(prefix)
                content = self._process_inline(list_match.group(2))

                # Check if we are increasing depth (nesting)
                if not self.list_stack or indent_level > self.list_stack[-1][0]:
                    self.list_stack.append((indent_level, True))
                    html_output.append("<ul>")
                    html_output.append(f"  <li>{content}</li>")
                
                # Check if we are at the same depth
                elif indent_level == self.list_stack[-1][0]:
                    html_output.append(f"  <li>{content}</li>")
                
                # Check if we are decreasing depth (closing levels)
                else:
                    while self.list_stack and indent_level < self.list_stack[-1][0]:
                        self.list_stack.pop()
                        html_output.append("</ul>")
                    
                    if self.list_stack and indent_level == self.list_stack[-1][0]:
                        html_output.append(f"  <li>{content}</li>")
                    else:
                        # If we exited all lists, start a new one
                        self.list_stack.append((indent_level, True))
                        html_output.append("<ul>")
                        html_output.append(f"  <li>{content}</li>")

            else:
                # It's a paragraph
                close_all_lists()
                content = self._process_inline(stripped)
                html_output.append(f"<p>{content}</p>")

        close_all_lists()
        return "\n".join(html_output)
```

### Key Changes Made:
1.  **Indentation Capture:** The `re_list_item` regex now captures the leading characters (`[\*\-\s]+`). This allows us to measure how "deep" the list item is.
2.  **The Stack:** Replaced `self.in_list` (bool) with `self.list_stack` (list of levels).
3.  **Depth Logic:** 
    *   If `current_indent > last_indent`: We `append` a new level and open a `<ul>`.
    *   If `current_indent < last_indent`: We `pop` from the stack and close `</ul>` tags until we match the current indentation.
4.  **Cleanup:** Added `close_all_lists()` to ensure that if a file ends or a heading appears, all nested `<ul>` tags are properly closed.<turn|>
